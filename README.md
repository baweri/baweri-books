# Baweri books

PDF books for the Baweri app, one file per book: `pdf/BOOK_ID.pdf`. The app downloads them through jsDelivr, for example:

```
https://cdn.jsdelivr.net/gh/baweri/baweri-books@main/pdf/7101.pdf
```

The book list that points to these files is in [baweri-content](https://github.com/baweri/baweri-content).
