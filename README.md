# Baweri books

PDF books for the Baweri app, one file per book: `pdf/BOOK_ID.pdf`. The app downloads them from the `pdf-v1` release, for example:

```
https://github.com/baweri/baweri-books/releases/download/pdf-v1/7101.pdf
```

Not through jsDelivr, which refuses packages over 50 MB. To add or change a book, upload it to the release as well.

The book list that points to these files is in [baweri-content](https://github.com/baweri/baweri-content).
